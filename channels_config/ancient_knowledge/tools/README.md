# Ancient Knowledge tools

Operator scripts for one channel. Run from the repo root.

| Script | What it does |
|---|---|
| `rebuild_silent_reels.py` | Remuxes the 2026-09-06 silent batch. |
| `repair_nazca_v02.py` | Rebuilds Nazca v02 stills and replaces the scheduled upload. |
| `reschedule_youtube.py` | Replaces the ten silent scheduled YouTube uploads. |
| `run_antikythera_e2e.py` | Locks the prior Antikythera voiceover and runs one reel. |
